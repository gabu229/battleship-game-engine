# Battleship Game Engine

A production-ready, framework-agnostic Battleship game engine built with TypeScript. This engine provides complete game logic without any UI dependencies, making it suitable for use across web, mobile, server, and bot implementations.

## Features

- ✅ **Framework Agnostic** - Works with React, Vue, Next.js, Node.js, React Native, etc.
- ✅ **Pure Business Logic** - No DOM, no window, no framework dependencies
- ✅ **Multiplayer Ready** - Supports local, and computer play
- ✅ **Type Safe** - Full TypeScript with strict mode
- ✅ **Event System** - Subscribe to game events for UI updates
- ✅ **Serializable** - Save/load game state to/from JSON
- ✅ **Deterministic** - Predictable behavior for testing and replay
- ✅ **Extensible** - Add custom weapons and bots
- ✅ **AI Bots** - vs computer with difficulty levels (Easy)
- ✅ **Special Weapons** - Multiple attack patterns
